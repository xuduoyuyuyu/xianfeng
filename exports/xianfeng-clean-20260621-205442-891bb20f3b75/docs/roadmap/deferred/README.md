# Deferred Roadmap

Future work accepted for tracking but not in active scope. Use this index
instead of creating generic backlog or ideas files.

## Entry Criteria

- The problem is real and worth preserving across sessions.
- It should not expand the current active plan.
- It has a clear owner component and acceptance criteria.
- It is broader than a local code TODO.

## Promotion Rule

When a deferred item becomes active, add or update a concrete item in
`../active-roadmap.md`, keep links between the entries, and change status when
the work completes or becomes obsolete.
