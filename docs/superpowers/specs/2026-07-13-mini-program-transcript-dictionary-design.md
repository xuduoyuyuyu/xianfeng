# 小程序逐字稿教育词典高亮设计

## 目标

在小程序原生节目详情页的逐字稿正文中，高亮后台节目详情接口返回的教育词典词条。用户点击高亮词语后，在当前页面查看该词条的真实释义。

## 范围

- 仅处理节目详情页的逐字稿正文。
- 不处理节目简介、速览、脉络或其他页面内容。
- 只使用节目详情已有的 `dictionaryEntries`，不生成或补写词条与释义。
- 不改变后台接口和持久化数据结构。

## 数据流

1. 小程序加载节目详情及其 `dictionaryEntries`。
2. 规范化有效词条：必须同时具有非空词条名称和释义；保留有效别名。
3. 对每段逐字稿正文执行最长词优先匹配。
4. 将正文拆分为普通文本节点和词典词条节点，保持原始文字及顺序不变。
5. 点击词条节点时，将对应词条写入当前页面弹窗状态。

## 匹配规则

- 正式词条名称和别名都可触发匹配。
- 候选词按文字长度降序匹配，避免短词截断长词，例如同时存在“国际教育”和“教育”时优先匹配“国际教育”。
- 同一段文字从左到右匹配，不重复覆盖已匹配区间。
- 重复出现的词语均高亮。
- 没有有效词典数据或正文没有命中时，逐字稿保持普通文本显示。
- 匹配仅改变展示节点，不修改逐字稿原文。

## 交互与视觉

- 高亮词沿用节目详情的紫色视觉体系，使用紫色文字和轻微底色，保持正文行高和可读性。
- 高亮词为可点击文本，不改变整段逐字稿的点击行为。
- 点击后显示当前页底部释义卡片和遮罩。
- 卡片展示词条名称、释义，以及存在时的别名。
- 用户可点击关闭按钮或遮罩关闭卡片。
- 弹窗打开期间不跳转页面、不发起新的词典请求。

## 异常与回退

- `dictionaryEntries` 缺失、不是数组或没有有效词条时，展示原始逐字稿。
- 词条缺少释义时不参与高亮，避免出现空弹窗。
- 别名为空、重复或与正式名称相同时忽略重复项。
- 点击状态对应的词条不存在时不打开弹窗。

## 验证

- 自动测试验证正式名称匹配。
- 自动测试验证别名匹配。
- 自动测试验证重叠词条采用最长词优先。
- 自动测试验证未命中文本保持原样。
- 静态页面测试验证高亮节点可点击、弹窗内容绑定、关闭按钮和遮罩关闭。
- 运行小程序完整静态测试，确认节目详情其他内容模式没有回归。

## 非目标

- 不修复或重新生成不完整的后台逐字稿。
- 不在其他小程序页面推广词典高亮。
- 不新增词典搜索、词条详情页或收藏功能。
- 不改变教育词典后台管理流程。
