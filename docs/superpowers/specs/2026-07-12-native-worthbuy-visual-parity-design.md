# 知物原生页面移动端视觉对齐设计

## 目标

微信小程序原生 `pages/worthbuy/index` 与 `pages/worthbuy-detail/index` 一比一复刻现有移动端网页 `/worthbuy` 与 `/worthbuy/:query` 的视觉层级和信息结构。网页 React 实现与用户提供的两张移动端截图共同构成唯一视觉基准；不重新设计，不改变现有 API、权限、Pro 点数、缓存和删除语义。

## 基准与边界

- 列表页基准：`frontend/src/pages/WorthBuyPage.tsx` 的移动端 Hero、输入区和商品卡片布局。
- 详情页基准：`frontend/src/pages/WorthBuyDetailPage.tsx` 的标题区、可信指数卡、多维评分及后续内容卡。
- 原生页面保留微信胶囊安全区与原生返回能力；网页公共导航不复制到内容区。
- 底部内容必须避让小程序固定 TabBar 和设备安全区。
- 不生成图片、插画或替代文案。网页中的商品 emoji、标签和真实字段按数据原样呈现；缺失字段不显示。
- 不修改 Web 页面，不把原生页面退回 WebView。

## 列表页

### 页面骨架

1. 全页使用 `#f8f6ff` 紫灰背景。
2. 顶部为轻量原生导航区：返回、品牌 Logo 和“知物”，高度由现有 `nativeChrome` 计算。
3. Hero 使用浅紫渐变/光晕背景、淡紫描边和约 32rpx 圆角；内部居中排列。
4. Hero 文案与网页一致：胶囊标题 `VALUE CHECK`、主标题“知物”、说明“输入商品链接或品牌名称，AI 帮你深度分析值不值得买，看穿消费迷雾”。
5. 输入框为白底大圆角单行视觉，左侧搜索图标；支持链接、分享文案和品牌名。主按钮位于输入框下方，空值为灰色禁用，存在输入时为网页紫色主按钮；保留真实 loading、登录、Pro 与点数错误状态。
6. 辅助说明使用网页文案：“支持淘宝、京东、拼多多等平台链接，或直接输入品牌名”。

### 卡片网格

- 默认公开列表直接接在 Hero 下方，不额外显示当前原生版的“公开知物”大标题行。
- 手机宽度使用两列等宽网格，列间距和行间距约 16rpx；窄屏仍保持两列但允许标题两行省略。
- 卡片为白底、浅紫边框、约 24rpx 圆角；内容水平排列：左侧商品 emoji/图标，右侧标题和紫色分类标签。
- 卡片数据从现有结果推导展示标题、emoji 与标签；不得拿评分数字替代网页卡片图标。
- “我的分析”入口保留，但收进 Hero 下方的次级切换，不破坏网页公开卡片的首屏结构；个人卡片的删除操作保持明确且不与整卡跳转冲突。
- 加载、空态、错误和继续加载采用同一背景与卡片语言，不显示虚构商品。

## 详情页

### 标题与主卡

1. 内容背景、横向留白和网页一致；顶部显示紫色“← 返回”、商品标题和“深度分析报告”。
2. 可信指数主卡为白底、浅紫边框、约 16px/32rpx 圆角。
3. 手机布局纵向居中：标题“可信指数”、180px 等效尺寸评分环、分数、评分结论、品牌/价格标签、原因说明与适用人群标签。
4. 评分环用原生 `conic-gradient` 不可用时的兼容结构实现：外环按分数切分为得分色和 `#F3F0FF`，内圆保持白色；最终观感必须与网页圆环一致，不使用普通实心圆替代。
5. 分数颜色与网页 `scoreColor` 分段一致；结论文本与网页 `scoreLabel` 一致。智商税和价格标签使用网页绿/橙与浅紫胶囊样式。

### 内容卡

- 多维评分卡复刻网页的五条评分：性价比橙、质量绿、安全性蓝、使用体验紫、售后粉；显示中文标签、浅紫轨道、彩色进度和右侧数值。
- 优点/注意、商业模式、评论分析、关键依据、适用人群、替代方案、综合建议和参考来源继续按真实字段条件渲染。
- 所有内容卡统一白底、浅紫细边、相同圆角和垂直间距；不再使用当前原生页混合的“大分数方块 + 简化文本”结构。
- 参考来源在小程序内继续复制链接，不伪装成可直接打开的浏览器链接。

## 数据映射

- 扩展 `worthbuyNative` 的展示归一化，使原生页获得网页需要的 `scoreLabel`、评分颜色、中文维度标签、卡片 emoji 和分类标签。
- 归一化只转换真实后端字段和既有网页规则；无数据字段保持空并由 WXML 条件隐藏。
- 列表分页、个人缓存 owner 隔离、提交防重复、登录/Pro/点数错误分类和详情分享路径保持不变。

## 验证

1. 静态测试覆盖 Hero 关键文案、两列卡片结构、详情评分环、五维颜色与条件内容块。
2. 运行知物 utility、列表、详情及侧边栏入口测试。
3. 运行小程序发布前静态校验；主工作区现有“妈妈好赚”失败若仍存在，单独标注，不混为知物回归。
4. 在微信开发者工具以与截图相同的手机宽度分别打开列表页和 `/pages/worthbuy-detail/index?query=试试`，截图与网页基准逐项比较。
5. 阻断级验收项：页面仍进入 WebView、首屏不是两列卡片、可信指数不是居中圆环、固定 TabBar 遮挡内容、真实字段被虚构文案替代。

## 非目标

- 不改变网页端视觉或内容。
- 不修改知物计费、分析算法、审核状态或发布策略。
- 不在本工作流上传微信版本或部署生产。
