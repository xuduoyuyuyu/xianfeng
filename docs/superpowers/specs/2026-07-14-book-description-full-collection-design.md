# 图书简介全量公开信源收集设计

## 目标

以 `及阅本地图书清洗版_20260714.xlsx` 中 2,404 本待重新收集图书为任务池，通过可恢复、可审计的多信源流水线完成全量查询。最终每本书必须进入 `已采纳`、`待人工复核` 或 `已穷尽信源` 三种终态之一；不为追求填充率生成、扩写或拼接简介。

本工作流只更新本地 Excel 和本地检查点，不修改线上数据库。生产写入仍遵循现有图书补全系统的独立放行机制，不属于本设计范围。

## 完成定义

“收集完”表示 2,404 本全部有终态：

- `已采纳`：找到可追溯、版本身份可靠、内容符合质量门槛的真实简介。
- `待人工复核`：存在候选简介，但身份、版本或信源强度不足以自动确认。
- `已穷尽信源`：规定信源均已查询，仍无可靠候选，并记录查询过的信源和失败原因。

不允许用虚构内容消除 `已穷尽信源`。

## 任务排序与批次

任务按身份字段完整度排序：

1. ISBN、书名、作者、出版社完整。
2. ISBN 完整，其他身份字段有缺失。
3. 无 ISBN，但书名、作者、出版社完整。
4. 仅有部分身份字段或存在明显版本歧义。

每批最多 100 本，预计约 25 批。每批完成后保存独立检查点和 Excel 快照；中断后从未终态任务恢复，不重复查询已完成记录。每完成 500 本生成一次累计覆盖率、信源成功率、冲突率和失败分类报告。

## 信源等级

### A 级

- 出版社、作者或版权方官方页面。
- 国家图书馆、高校图书馆等可验证馆藏页面。
- 能由规范化 ISBN 精确定位的官方版本接口。

### B 级

- Google Books 的精确版本记录。
- Open Library 的精确 edition 记录。
- 可信图书销售平台中可确认 ISBN 或完整版本身份的页面。

### C 级

- 聚合搜索结果、转载页面、内容农场。
- 无法确认版本的书评、推荐文章或列表页。

C 级只提供发现线索，不得作为自动采纳的唯一证据。

每个信源独立设置并发、超时、限速和退避。单一信源限流或不可用时，任务继续查询其他信源；不得让 Google Books 或任何单一来源成为全批阻塞点。

## 身份匹配

- A 级身份：ISBN-10/13 规范化后精确一致。
- B 级身份：无 ISBN 时，规范化书名与作者精确一致，并满足出版社一致或两个独立信源一致。
- C 级身份：只有书名相似、作者缺失，或存在译者、出版社、出版年份、版本冲突。

同名不同作者、不同译本和不同出版社版本必须拆分判断。任何 C 级身份候选都不得自动采纳。

## 简介质量门槛

候选简介必须同时满足：

- 对故事、主题、知识内容或作品价值进行连贯表述。
- 有效字符不少于 50。
- 不属于作者、出版社、适龄、标签等字段模板拼接。
- 不属于目录、作者简介、读者评论、推荐语或促销文案。
- 不跨书重复，不得把同一段简介复用到不同书目。
- 保留来源原文；只允许去除 HTML、导航、营销尾注和无关空白，不允许 AI 扩写。

每个候选保存原始文本哈希、清洗后文本、来源 URL、信源等级、抓取时间、版本身份依据和拒绝原因。

## 自动采纳门槛

满足以下任一条件可进入 `已采纳`：

- ISBN 精确一致，且简介来自 A 级信源。
- ISBN 精确一致，且两个独立 B 级信源提供相同或实质一致的简介。
- 无 ISBN，但达到 B 级身份匹配，且一个 A 级内容来源或两个独立 B 级内容来源一致。

只有单个 B 级候选、身份字段有缺失或候选之间存在版本冲突时进入 `待人工复核`。无可靠候选且所有规定信源已完成查询时进入 `已穷尽信源`。

## 本地数据结构

本地任务记录至少包含：

- 图书 ID、书名、作者、出版社、ISBN。
- 批次编号、任务状态、查询次数、最后查询时间。
- 已查询信源、信源结果和失败分类。
- 身份匹配等级、字段置信度和仲裁原因。
- 主信源名称与 URL、辅助信源 URL。
- 原始候选简介、采纳简介、未采纳原因。

最终 Excel 保留原始图书字段、清洗前简介和清洗原因，并增加：

- `收集后简介`
- `收集状态`
- `置信度`
- `身份匹配等级`
- `主信源名称`
- `主信源URL`
- `辅助信源URL`
- `原始候选简介`
- `未采纳原因`
- `已查询信源`
- `查询次数`
- `最后查询时间`
- `批次编号`

候选证据单独保存在“信源证据”工作表，一条候选一行，不把多个来源压缩为不可审计的长字符串。

## 失败处理与恢复

- 限流和临时网络错误采用分信源指数退避，并保留下一次可重试时间。
- 无匹配、身份冲突、内容过短、模板拼接、重复内容和促销文案分别记录明确错误码。
- 单本书的一个信源失败不阻止其他信源继续。
- 同一任务达到各信源规定重试上限后，根据已有证据进入 `待人工复核` 或 `已穷尽信源`。
- 检查点采用原子替换保存；恢复时只调度未终态或已到重试时间的任务。

## 质量控制

每批 100 本完成后抽查：

- 10 本 `已采纳`。
- 5 本 `待人工复核`。
- 5 本 `已穷尽信源`。

自动检查包括：模板拼接、少于 50 个有效字符、跨书重复、来源 URL 缺失、版本冲突、同一信源重复计数和终态缺少原因。

当抽查发现误匹配或不合格简介时，该批不得合并进累计 Excel；修正规则后重跑该批。

## 最终验收

- 2,404 本全部有且仅有一个终态。
- 每条 `已采纳` 简介都有可访问的主信源 URL 和身份依据。
- 自动采纳记录全部满足身份、信源和内容门槛。
- 字段模板拼接、跨书重复简介和无来源采纳均为 0。
- `已穷尽信源` 记录包含已查询信源、查询次数和明确原因。
- 批次统计之和与最终 Excel 总数一致，检查点可恢复。
- 最终输出一个完整 Excel；不修改 MongoDB 或线上接口数据。
