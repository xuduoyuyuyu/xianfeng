# 福利领取链接直接打开设计

## 目标

福利领取成功弹窗中，当后台返回 `#小程序://` 微信小程序短链时，用户点击“点击获取”应直接打开目标小程序，不再只复制链接。

## 交互规则

- 小程序短链继续显示“点击获取”。按钮和链接区域都调用现有 `openClaimLink` 行为。
- `openClaimLink` 使用 `wx.navigateToMiniProgram({ shortLink })` 打开目标小程序。
- 普通 HTTP 链接继续显示“复制链接”，继续调用现有复制行为。
- 小程序短链无法打开时，保留现有复制兜底与提示，不改变领取状态。

## 实现范围

- 修改 `apps/wechat-miniprogram/pages/welfare/index.wxml` 的按钮事件绑定。
- 增加静态回归测试，验证小程序短链按钮调用打开行为，普通链接仍调用复制行为。
- 不修改后台字段、领取接口、弹窗样式或其他页面。

## 验收标准

1. 小程序短链对应的“点击获取”按钮不再绑定 `copyClaimLink`。
2. 点击按钮直接触发 `openClaimLink`。
3. 普通链接仍显示“复制链接”且保持复制行为。
4. 福利页相关测试及小程序静态测试通过。
