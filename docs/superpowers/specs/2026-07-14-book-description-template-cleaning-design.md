# 图书拼接简介清洗与 Excel 重建设计

## 目标

从线上 `/api/books` 合并响应读取 2,779 本图书，在不修改线上数据库的前提下，识别并移除字段模板拼接形成的伪简介，生成可用于后续重新采集的 Excel。

## 判定规则

简介中的以下结构标记作为模板特征：

- `作者/著作者：`
- `出版社：`
- `适用/关联范围：`
- `现有标签：`
- 独立段落开头的 `标签：`

当一条简介命中至少两个不同模板特征时，判定为“字段拼接简介”。命中后不截取或改写局部内容，清洗后简介直接置空。仅命中一个特征，或未达到阈值的连贯叙述，原样保留，避免误删正常内容。

## Excel 数据结构

“图书总表”保留全部线上合并字段，并增加：

- `原始简介`
- `清洗后简介`
- `简介清洗状态`：`保留`、`移除拼接简介`、`原本为空`
- `简介清洗原因`：记录命中的模板特征

用于后续补充的主 `简介` 字段采用清洗后的值。原始响应仍完整保存在“图书原始数据”工作表，确保清洗结果可追溯。

概览页展示：图书总数、原始非空简介数、移除拼接简介数、清洗后有效简介数、待重新收集简介数。

## 数据边界

- 只生成本地 Excel，不写入 MongoDB，不调用线上编辑接口。
- 不把标签、作者、出版社等字段拼接为替代简介。
- 不生成或推测新的简介；重新采集属于后续独立工作。
- 线上接口未公开的正式详情分项继续保持为空，不伪造详情记录。

## 验证

- 示例《七彩下雨天》应判定为“移除拼接简介”。
- 抽查命中记录，确认至少包含两个模板特征。
- 抽查保留记录，确认是连贯叙述且未达到模板阈值。
- 核对：原始非空简介数 = 移除数 + 清洗后有效简介数。
- 扫描 Excel 公式错误，并渲染检查全部工作表。
