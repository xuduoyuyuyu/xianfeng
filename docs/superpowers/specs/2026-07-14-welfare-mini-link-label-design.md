# 福利小程序短链按钮文案设计

## 目标

在福利领取成功弹窗中，根据外部链接内容区分按钮文案，使包含“小程序”的链接显示“点击获取”，普通链接继续显示“复制链接”。

## 范围

- 移动网页：`frontend/src/pages/WelfarePage.tsx`。
- 微信小程序原生福利页：`apps/wechat-miniprogram/pages/welfare/index.js` 与 `index.wxml`。
- 仅影响福利领取成功弹窗，不影响资料页、妈妈好赚任务内容或其他复制入口。

## 行为

- `externalUrl` 包含连续文本“小程序”时，按钮文案为“点击获取”。
- 其他非空 `externalUrl` 的按钮文案仍为“复制链接”。
- 移动网页点击行为保持现有复制逻辑。
- 小程序端外层链接点击、短链打开、复制按钮事件和失败提示均保持现状，仅按钮文案按链接内容变化。

## 数据与实现

- 不修改后端数据结构或接口。
- 移动网页从当前弹窗的 `externalUrl` 直接计算按钮文案。
- 小程序在设置领取弹窗数据时同步设置布尔值，WXML 根据该值渲染文案；关闭弹窗时重置该值。

## 验证

- 移动网页静态测试覆盖“小程序”链接使用“点击获取”及普通链接保留“复制链接”。
- 小程序静态测试覆盖布尔状态计算、重置和 WXML 条件文案。
- 运行福利页测试和小程序 `tab-webview.static.test.mjs`。
