# 妈妈好赚任务转账截图设计

## 目标

用户提交任务完成链接与完成截图后，运营可以在后台对应的用户任务记录上上传或替换转账截图。该任务的用户可在移动端和微信小程序任务详情中查看截图，作为本次任务已转账的反馈。

## 范围

- 转账截图归属于 `MamaResourceTaskAssignment`，即一个任务与一个用户账号形成的派发记录。
- 每条派发记录最多保存一张当前有效截图；再次上传即替换。
- 运营负责上传和替换，用户端只读。
- 历史派发记录允许没有转账截图。
- 不新增转账金额、流水号、支付状态、多图历史或用户确认收款能力。
- 不改变任务领取、用户回填、审核收录和驳回流程。

## 数据与接口

`MamaResourceTaskAssignment` 新增：

- `transferScreenshotUrl?: string`：当前转账截图地址。
- `transferScreenshotUpdatedAt?: Date | null`：最近一次上传或替换时间。

后台沿用现有受管理员权限保护的图片上传能力。上传成功后，前端调用派发记录更新接口写入截图地址；更新接口只允许后台访问，并返回序列化后的派发记录。

面向用户的任务列表与任务详情继续通过当前登录用户的 `profileId` 查询派发记录。公共任务模板不包含截图；只有归属当前用户的派发记录才会返回 `transferScreenshotUrl` 和更新时间。

## 后台交互

在任务管理弹窗的每条已分配账号记录中：

- 保留专属内容链接、完成链接、完成截图和审核操作。
- 增加“转账截图”区块。
- 未上传时显示“上传转账截图”。
- 已上传时显示图片预览、最近更新时间和“替换截图”。
- 上传或保存失败时保留原截图，并显示明确错误信息。
- 上传期间只禁用当前上传动作，避免重复提交。

运营可在用户提交前或审核后上传截图，但产品语义仍是任务级转账反馈，不自动改变任务状态。

## 用户端交互

移动端和小程序端在已领取任务详情中增加只读“转账凭证”区块：

- 有截图时显示图片，点击可查看大图。
- 无截图时不渲染该区块，不显示占位提示。
- 用户不能上传、删除或替换转账截图。
- 任务完成链接、完成截图和现有回填操作保持不变。

## 权限与兼容

- 后台更新接口继续使用管理员鉴权。
- 用户只能通过现有 `/me/tasks` 归属查询看到自己的派发记录，不能用派发记录 ID 查看他人的截图。
- 历史数据不迁移；缺少新字段时按无截图处理。
- 图片地址使用现有上传返回值与图片 URL 规范，不新增外部存储。

## 验证标准

- 模型可保存转账截图地址和更新时间。
- 后台可以为指定派发记录上传、保存、预览和替换截图。
- 保存截图不会改变任务状态。
- 用户任务列表和详情仅返回当前用户自己的截图。
- 移动端与小程序端仅在有截图时展示只读凭证，并可查看大图。
- 其他用户无法通过用户接口读取该截图。
- 现有任务回填、审核、专属内容链接及历史无截图记录保持可用。
