# 及阅可购买卡片标签筛选设计

## 目标

及阅列表中的可购买内容同时支持主题标签筛选和购买跳转。点击主题标签只在当前及阅页面筛选；点击卡片其余区域或右下购物车按钮继续跳转购买。

## 交互边界

- `#` 开头的主题标签使用现有 `onReadingTagTap` 筛选逻辑，并通过 `catchtap` 阻止事件冒泡。
- 推荐方文字保持普通信息，不参与筛选。
- 卡片封面、标题、作者/出版方、描述、分类和空白区域沿用卡片 `bindtap="openBook"`。
- 购物车按钮位于卡片内，沿用卡片跳转行为。
- 不改变非购买内容的标签筛选逻辑。

## 验证

- 静态测试证明可购买内容的主题标签具备 `data-tag` 和 `catchtap="onReadingTagTap"`，且不存在购买标签的不可点击分支。
- 运行及阅相关静态测试、JavaScript 语法检查和定向 `git diff --check`。
- 微信开发者工具现场分别点击标签、卡片空白区域和购物车按钮。
