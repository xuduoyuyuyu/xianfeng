# 妈妈好赚内容下发弹窗设计

日期：2026-07-14

## 目标

将管理员端“内容下发”从混合任务管理界面调整为独立的大尺寸弹窗。弹窗只服务当前任务的账号筛选、账号分配和专属内容链接管理，不承载任务看板、任务创建或任务编辑。

## 页面入口

- 任务列表中的当前“账号选号”动作改名为“内容下发”。
- 点击后打开当前任务的内容下发弹窗，并加载该任务的候选账号和已分配账号。
- 任务创建与任务编辑继续使用主页面现有入口和既有弹窗，不迁移到内容下发弹窗。

## 弹窗结构

- 弹窗使用接近视口宽度的大尺寸布局，并保留合理的页面边距和纵向滚动。
- 顶部只显示“内容下发”、当前任务名称、简短说明和关闭按钮。
- 主体上方为整行筛选区，保留昵称/微信/链接、品类标签、风险标签和最低粉丝数条件，以及“筛选账号”动作。
- 主体下方采用双栏布局：左侧为“定向选择账号”，右侧为“已分配账号”。
- 已分配账号区域继续提供专属内容链接的逐条保存、模板下载和批量导入能力。
- 弹窗内不显示任务看板、已上架任务列表、“上架新任务”入口或任务编辑入口。

## 状态与数据流

- 弹窗打开时复用现有当前任务选择及 `loadTaskWorkspace` 数据加载流程。
- 筛选条件、候选账号选择、账号分配、专属链接保存和 Excel 导入继续使用现有状态和 API。
- 关闭弹窗只关闭当前工作区，不创建、编辑或切换任务。
- 本次不修改后端接口、任务模型、分配规则或链接校验规则。

## 错误与加载状态

- 沿用现有账号加载、空候选、空分配、保存失败和导入失败提示。
- 加载期间继续禁用会重复提交的分配与保存动作。
- 不新增兜底文案或模拟数据。

## 验收标准

1. 点击任务列表的“内容下发”可打开大尺寸弹窗。
2. 弹窗标题明确对应当前任务。
3. 弹窗仅包含筛选区、定向选择账号和已分配账号相关内容。
4. 弹窗内不存在任务看板、已上架任务列表和“上架新任务”入口。
5. 账号筛选、分配、专属链接保存、模板下载和批量导入行为保持可用。
6. 任务创建和任务编辑仍可从主页面原有入口使用。
7. 桌面浏览器实际渲染下，弹窗明显大于当前混合工作区，双栏内容无需被左侧任务栏挤压。

## 验证

- 更新管理员页面静态契约测试，先观察新断言在旧实现上失败，再完成最小实现并观察通过。
- 运行 `node --test frontend/src/pages/admin/AdminMamaResourcesPage.test.mjs`。
- 运行 `npm run build`。
- 启动本地页面后，通过浏览器检查真实弹窗宽度、标题、入口文案和内容范围。

## 非目标

- 不改任务创建表单、任务字段或任务编辑流程。
- 不改账号审核页。
- 不改后端 API、数据库或生产数据。
- 不调整内容链接导入格式、校验规则或短信下发语义。
