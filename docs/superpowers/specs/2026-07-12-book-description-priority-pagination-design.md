# 及阅有简介图书全局前置设计

## 目标

`/api/books` 的分页结果应在全部已发布图书范围内优先展示有真实简介的图书，避免只有第一页集中出现简介。

## 排序口径

满足以下任一条件即属于“有简介”：

- 存在审核通过的图书元数据简介；
- 图书基础记录的 `description` 存在非空文本。

全部已发布图书分为“有简介”和“无简介”两组。有简介组整体排在无简介组之前；每组内部继续按 `publishedAt`、`_id` 倒序，保证分页顺序稳定。

## 数据流

后端分页函数先确定所有有审核简介的图书 ID，再把基础记录中 `description` 非空的图书纳入同一优先集合。分页偏移量先消耗优先集合，剩余页容量再从无简介集合读取。响应结构、简介字段合并规则和前端追加加载逻辑保持不变。

## 边界

- 不生成或伪造简介；
- 不修改图书数据、元数据内容或审核状态；
- 不改变未分页 `/api/books` 的既有接口形态；
- 不修改小程序或 Web 前端展示。

## 验证

- 回归测试证明基础 `description` 非空的图书会与有审核元数据简介的图书一起进入优先集合；
- 回归测试证明分页跨越两组边界时不会漏书、重书；
- 运行图书控制器相关测试；
- 用本地或线上只读统计验证前若干页的简介覆盖率符合全局前置规则。
