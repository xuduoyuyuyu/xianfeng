# 妈妈好赚专属内容链接下发设计

日期：2026-07-14  
状态：已确认

## 目标

运营为同一妈妈好赚任务中的不同账号配置不同的飞书内容链接。用户登录后只能在自己的任务详情中看到对应链接，并在发布后沿用现有的作品链接、完成截图、审核与结算流程。

本期只下发链接，不抓取飞书正文、不转存飞书图片，也不接入飞书开放平台。

## 范围

本期包含：

- 在用户任务分配记录上保存专属内容链接。
- 后台支持逐个手动填写和 Excel 批量导入。
- Excel 导入可同时完成账号分配和链接写入。
- 运营确认后创建一次短信下发批次。
- 后台展示链接配置进度与短信发送状态。
- 用户在自己的任务详情中打开或复制专属链接。

本期不包含：

- 解析、复制或缓存飞书页面内容。
- 将飞书图片保存到本地素材库。
- 自动生成用户文案。
- 链接保存后自动发送短信。
- 改变现有任务提交、审核或结算语义。

## 数据归属

`MamaResourceTask` 继续保存项目、价格、时间、发布要求和结算标准等公共任务信息。

`MamaResourceTaskAssignment` 保存用户在该任务中的专属状态，并增加：

- `contentUrl`：该账号的专属飞书内容链接。
- `contentUpdatedAt`：链接最后更新时间。
- 短信下发状态所需的最近成功发送时间或批次关联信息。

同一任务与账号仍以现有的唯一分配记录为准。再次录入或导入时更新 `contentUrl`，不创建重复分配。

短信下发使用独立批次记录，至少包含：

- 任务 ID、操作人、创建时间。
- 目标数、成功数、失败数、跳过数。
- 每位用户的分配记录、手机号、链接版本、发送状态、发送时间和短信服务返回结果。
- 可用于幂等控制的批次与收件人唯一键。

下发批次保存当时的链接版本。链接后续修改不篡改历史发送记录。

## 后台手动填写

入口位于现有“任务上架和账号选号”的已选或已分配账号区域。

- 每个账号显示“专属内容链接”输入项。
- 运营可新增、修改并保存链接。
- 保存只更新任务分配，不自动发短信。
- 已发送短信后修改链接，页面标记“链接已更新，尚未重新通知”。
- 任务列表显示链接配置进度，例如“已配置 18/20”。

## Excel 批量导入

后台在当前任务的账号选号/已分配账号区域提供“批量导入专属链接”和模板下载。

模板只要求两列：

| 列名 | 说明 |
| --- | --- |
| 妈妈好赚账号ID | 系统导出的稳定账号标识，不使用达人名称匹配 |
| 专属内容链接 | 该用户对应的飞书内容链接 |

导入分为预检与确认两个阶段：

1. 上传 `.xlsx`，只解析和校验，不立即写入。
2. 预检展示总行数、可导入数、账号不存在、链接为空、链接格式错误和重复账号。
3. 展示将新增分配与将覆盖链接的数量。
4. 运营确认后批量写入。
5. Excel 中尚未分配给当前任务的有效账号，同时创建任务分配并写入链接。
6. 同一任务、同一账号已有记录时覆盖链接，不重复创建分配。

单行错误不阻止查看其他行的预检结果。运营明确确认后，只写入预检成功行；失败行保留原因供修正后重新导入。

## 短信下发

链接录入和短信发送严格分离。后台提供“下发任务并发送短信”按钮，由运营主动触发。

点击后先展示：

- 本次待通知人数。
- 缺少专属链接人数。
- 缺少手机号人数。
- 已成功发送、将被跳过的人数。

运营确认后创建一次独立下发批次。只发送给同时满足以下条件的分配：

- 已分配到当前任务。
- 已配置有效的 `contentUrl`。
- 有可用手机号。
- 当前链接版本尚无成功短信记录。

同一批次的页面刷新、重复点击或接口重试不得重复发送。已成功发送的用户显示“短信已发送”和发送时间；失败用户显示失败状态，支持单个重试和“重试失败短信”。

链接修改后允许运营再次通知，但必须重新点击发送，不自动触发。

短信不携带飞书长链接，统一通知用户进入妈妈好赚查看，例如：

> 【家长先疯】你的妈妈好赚专属发布内容已下发，请进入小程序“妈妈好赚—我的任务”查看并按要求发布。

实际模板 ID、签名、频控与服务商错误码沿用项目现有短信服务约定；若现有服务不支持该模板，实施前需先完成模板申请与配置。

## 用户端

任务列表对已配置链接的分配显示“专属内容已下发”。任务详情提供“打开专属发布内容”主操作，并提示用户进入后复制文案、保存图片，再返回提交发布结果。

小程序优先通过现有允许的 WebView 路径打开链接。若飞书域名未进入小程序业务域名或实际设备无法打开，则提供“复制链接”，提示用户在外部浏览器访问。WebView 与复制回退必须在真实微信开发者工具和设备上验证，不能只依赖静态测试。

公开接口只返回当前登录用户所拥有分配的 `contentUrl`。后台接口仍需管理员权限。接口不得按任务 ID 暴露其他账号的专属链接列表给普通用户。

## 错误处理

- 非 HTTP(S) 链接在手动保存和导入预检时拒绝。
- 账号 ID 不存在时不自动按名称或手机号猜测匹配。
- Excel 重复账号在预检中明确提示，避免静默采用首行或末行。
- 短信失败保留服务商结果并允许重试，不回滚已经保存的链接或任务分配。
- 缺手机号或缺链接记为跳过，不计为短信发送失败。
- 用户打开链接失败时仍可复制链接，不隐藏专属内容入口。

## 验证标准

后端测试覆盖：

- 手动新增和更新 `contentUrl`。
- Excel 预检、成功导入、自动创建分配、覆盖更新和错误行处理。
- 普通用户只能读取自己的专属链接。
- 下发批次幂等，接口重试不重复发送。
- 已发送、失败、缺手机号、缺链接与链接更新后的状态。
- 失败短信重试只处理符合条件的收件人。

前端与小程序验证覆盖：

- 后台手动填写、模板下载、上传预检、确认导入和链接配置进度。
- 下发确认信息、发送结果、失败重试和“短信已发送”标记。
- 用户任务卡与详情页的专属内容状态。
- 微信开发者工具和真实设备上的飞书链接打开与复制回退。

## 风险与假设

- 本期假设运营提供的飞书链接对目标用户可访问；系统只验证 URL 格式，不验证飞书页面内容或分享权限。
- 飞书链接内容被修改、删除或改变权限时，妈妈好赚不会保留历史副本。
- 短信属于外部付费能力，真正发送前必须具备可用模板、签名、余额和服务商配置。
- WebView 能否直接打开取决于微信业务域名与飞书跳转行为，实施结果必须保留复制链接回退。
