# 结构化语言盘点工具箱产品设计

日期：2026-08-13
状态：active

## 产品定位

`闪测` 不与通用聊天机器人竞争开放对话能力。它提供固定任务、可复测结果、逐项证据和长期变化记录，把一次回答变成可追溯的学习盘点。

产品承诺是：

- 说明这次具体测了什么。
- 保存孩子在每个题项上的真实作答过程，而不只保存总分。
- 区分独立完成、提示后完成、跟读完成和暂未完成。
- 让每个结论追溯到题库版本、任务规则、评分证据和参考来源。
- 把结果连接到下一次练习和延迟复测。

产品不承诺：

- 用少量随机题推算完整中文或英文词汇量。
- 输出智力、心理、学习障碍或医学诊断。
- 因为引用某个框架就声称获得该框架或机构认证。
- 让大语言模型临时改变正式题库、测量目标或评分口径。

## 首个产品切片

首个新增工具为 `英语看图说词`。它验证语音任务、证据评分和复测状态，再与现有 `识字量` 一起提取共享能力；本期不先建设脱离真实工具的通用测试平台。

第一版使用一个固定、版本化的 50 词试验词库，优先选择真实照片能够明确指向的生活名词。所有题图必须是相机拍摄的真实世界照片，禁止 AI 生成、插画、3D 渲染和合成主体。验证完成后再扩展成四组各 50 词，每组独立开始、退出续测和保存结果。

首版词目、允许答案、图片消歧和素材验收规则见[英语看图说词首版 50 词内容基线](2026-08-13-english-picture-naming-pilot-bank.md)。

每个单词按同一协议运行：

1. 只显示图片，孩子独立说出英文。
2. 语音识别判断说出的候选词，并与题目允许答案匹配。
3. 英文口语评测根据匹配到的目标词返回单词级和可用的音素级证据。
4. 独立作答失败时显示单词并播放标准音，允许跟读一次。
5. 记录最终状态，但保留首次独立作答和提示过程，不用最终跟读覆盖首次结果。
6. 需要巩固的单词进入后续练习，并在延迟窗口重新以无提示方式出现。

结果页使用可解释状态，不显示来源不明的单一综合分：

- `独立说出且发音稳定`
- `独立说出，发音需练习`
- `提示后会读`
- `暂不会`
- `环境或录音无效，需要重试`

结果表述固定为“本组 50 个词中……”，不得外推为孩子的完整英语词汇量。

## 语言任务矩阵

语言工具由输入、响应和测量对象共同定义，不能只按“中文测试”或“英文测试”命名。

| 输入 | 响应 | 主要测量对象 | 示例工具 |
| --- | --- | --- | --- |
| 图片 | 说出词语 | 主动词汇、独立提取、发音 | 英语看图说词 |
| 音频 | 选择图片 | 接收性词汇、听力辨别 | 英语听词选图 |
| 文字 | 朗读 | 字词解码、字音或发音 | 中文字词朗读、英文单词朗读 |
| 音频 | 输入或书写 | 音形对应、拼写或听写 | 英文拼写、中文听写 |
| 场景 | 回答问题 | 口语产出、互动 | 看图问答 |
| 指令音频 | 完成选择或动作 | 听力理解、实际运用 | 听指令做动作 |
| 短文 | 回答问题 | 阅读理解 | 中文或英文短文理解 |

每个测试定义必须明确标记：

- `inputModality`：图片、音频、文字、场景或组合。
- `responseModality`：选择、口语、输入、书写、操作或组合。
- `constructs`：主动词汇、接收性词汇、解码、发音、拼写、听力理解等具体对象。
- `activityModes`：与参考框架对应的接收、产出、互动、中介，可多选但必须说明本题真正覆盖的部分。

## 标准引用层

标准、课程、题库依据、评分方法和供应商能力都作为产品数据，而不是只写在页面底部的宣传文案。

### 引用类型

| 类型 | 用途 | 不得暗示 |
| --- | --- | --- |
| `framework` | 定义语言活动、能力维度或描述框架 | 官方认证或等级等同 |
| `curriculum` | 约束年龄、学段、内容范围和措辞 | 某题库就是官方指定题库 |
| `assessment-example` | 参考成熟的任务结构和儿童交互 | 复制对方考试或获得授权 |
| `measurement` | 约束自动评分、人工复核和有效性验证 | 算法分数天然等于真实能力 |
| `content-source` | 说明单词、汉字、图片和标准音的具体来源 | 来源覆盖完整能力范围 |
| `vendor-capability` | 说明 ASR、口语评测、TTS 提供什么技术证据 | 供应商分数就是产品最终结论 |

### 引用实体

每条 `ReferenceSource` 至少保存：

- `referenceId`
- `referenceType`
- `title`
- `issuer`
- `editionOrDate`
- `url`
- `scope`
- `limitations`
- `checkedAt`

每条 `ReferenceLink` 把来源连接到具体对象：

- 测试定义
- 题库版本
- 任务模板
- 评分规则
- 结果解释
- 技术能力声明

连接还要写明 `claim`：这个来源具体支持哪一句规则。一个来源不能因为被引用，就自动支持整个测试。

### 产品中的引用展示

- 测试介绍页显示紧凑来源标记，例如 `[R1] [R3]`。
- 点击标记打开来源抽屉，显示机构、版本、用途、限制和可复制链接。
- 结果页的解释、评分说明和题库说明分别显示自己的引用，不能共用一个模糊的“参考国际标准”。
- 后台或调试视图能从结果快照追到当时使用的引用版本；后来更新引用不得改写历史结果。
- 用户分享不携带孩子作答和录音，但可携带公开的测试定义及来源说明。

## 工程化六层

### 1. 版本化题库

`ItemBankVersion` 固定题项、顺序或抽题规则、可接受答案、素材、标准音、难度标签、内容来源和生效时间。

- 已开始的测试锁定题库版本。
- 新版本不得改写旧结果。
- 图片存在多个合理英文名称时，明确列出允许答案；无法稳定消歧的图片不进入正式题库。
- 图片、标准音和文字必须拥有明确来源或使用权记录。
- 图片资产必须能证明来自真实拍摄；生成式填充、生成式扩图、主体合成、背景替换和无法确认来源的“写实图片”不得入库。

### 2. 标准任务协议

`TaskProtocolVersion` 定义每一步显示什么、允许几次作答、何时给提示、何时播放标准音、如何退出续测以及哪些事件计入结果。

同一测试的首次作答、提示、跟读和家长复核必须保存为不同事件。界面升级可以不改变协议；协议改变时必须更新版本。

### 3. 多证据评分

`EvidenceBundle` 汇总但不混淆：

- ASR 候选词与置信度。
- 目标词匹配结果。
- 口语评测的单词级、音素级和录音质量证据。
- 设备、噪声、时长等质量信号。
- 家长复核及复核原因。
- 使用的评分规则版本和供应商能力引用。

产品规则根据证据得出可解释状态。供应商原始分数不得直接作为孩子的最终能力结论；低置信度必须重试或进入人工复核。

### 4. 逐项掌握图

`MasteryState` 以孩子、语言、题项和能力对象为边界，记录最新状态及证据来源。

它不是一张笼统雷达图，而是可以回答：

- 哪些词能独立提取。
- 哪些词只在提示后能读。
- 哪些音素反复不稳定。
- 哪些词在不同任务中表现不同，例如能听懂但不能主动说出。

不同孩子、不同账号、不同题库版本必须隔离。跨测试合并只能通过明确的共同能力节点，不能按相同文字字符串自动合并。

### 5. 延迟复测

`ReviewSchedule` 只把即时完成视为一次证据，不自动等同长期掌握。

- 提示后完成的题项进入较近复测。
- 独立完成但发音不稳定的题项进入发音复测。
- 已稳定题项降低出现频率，但保留周期性校验。
- 延迟复测仍以无提示首次作答为主，不能先播放答案。

复测策略先使用简单、可解释的固定间隔；积累足够数据后才评估自适应间隔。

### 6. 结果到练习闭环

`PracticePrescription` 从真实错误类型生成下一步任务：

- 暂不会的词进入图片到口语练习。
- 知道词义但发音不稳定的词进入音素对比和跟读。
- 只能听懂不能说出的词进入主动提取练习。
- 录音质量失败只要求重录，不进入能力弱项。

练习可使用 AI 生成解释或变式，但必须引用已确认的目标词、能力节点和模板；AI 不得修改正式掌握状态。

## 核心数据对象

第一阶段只实现两个真实工具需要的字段，不预建完整后台平台。

| 对象 | 责任 |
| --- | --- |
| `AssessmentDefinition` | 测试目标、适用对象、任务组合、引用和结果口径 |
| `ItemBankVersion` | 固定题库及素材版本 |
| `AssessmentItem` | 单个题项、允许答案、能力节点和来源连接 |
| `TaskProtocolVersion` | 作答、提示、跟读、退出和复测规则 |
| `AttemptEvent` | 每一次显示、录音、选择、提示、复核和重试 |
| `EvidenceBundle` | ASR、口语评分、质量和人工证据 |
| `ResultSnapshot` | 完成时不可变的测试结果与引用版本 |
| `MasteryState` | 孩子在具体能力节点上的当前状态 |
| `ReviewSchedule` | 下一次无提示复测时间和原因 |
| `ReferenceSource` / `ReferenceLink` | 来源实体及其支持的具体规则 |

## AI 与规则的边界

AI 可以：

- 把已确认错误解释成儿童可理解的反馈。
- 在固定目标、模板和词表内生成练习变式。
- 总结多个结果快照中的真实变化。
- 在低置信度时生成候选供家长复核。

AI 不可以：

- 临时决定正式测试范围。
- 改写题库、允许答案或评分阈值。
- 用对话印象覆盖结构化证据。
- 直接授予或撤销掌握状态。
- 把供应商分数包装成诊断、官方等级或完整词汇量。

## 产品界面信息架构

### 测试目录

测试卡保留简洁目录结构，并增加紧凑的“任务类型”与来源标记。例如：

- `英语看图说词`
- `产出 · 发音`
- `固定 50 词 · 可续测`
- `[R1] [R5]`

### 测试介绍

介绍页说明：

- 本次具体测试的输入和响应方式。
- 能回答什么、不能回答什么。
- 题库数量和版本。
- 是否录音、原始录音是否保存。
- 使用的语言活动框架和技术证据来源。

### 测试过程

- 首次看图阶段不显示答案或播放标准音。
- 录音状态、网络处理和噪声重试明确区分。
- 提示和跟读是后续阶段，视觉上不能伪装成首次独立作答。
- 退出保存当前题项和协议阶段，重新进入继续同一题库版本。

### 结果与来源

- 先显示本题库内的精确状态数量。
- 再显示可操作的单词和音素清单。
- 每段解释旁显示对应来源或评分规则引用。
- 来源抽屉区分教育框架、内容来源、测量方法和供应商能力。
- 显示下一次复测安排及原因。

## 数据和隐私边界

- 复用现有账号和孩子档案绑定；不创建第二套孩子身份系统。
- 默认不长期保存儿童原始录音。完成评测后只保存必要的结构化证据；需要保留样本做校准时必须走单独、明确的授权流程。
- 结果分享不携带孩子身份、录音、答案、进度或掌握图。
- 家长复核需要记录来源和时间，不能静默覆盖自动评分。
- 账号退出、切换和删除时遵守现有私有缓存与账号边界。

## 交付阶段

### 阶段 1：任务、照片与供应商验证

- 固定 50 个真实照片指向明确的试验词。
- 为每张照片保存拍摄或采购来源、摄影者、许可、人物或财产权利授权、编辑记录和原始/成品哈希。
- 使用成人与经过单独授权的儿童样本验证正确词、错误词、常见发音偏差、静音和噪声。
- 确认火山英文口语评测实际返回字段、延迟、失败类型和计费。
- 定义第一版可解释状态，不直接沿用供应商默认阈值。

### 阶段 2：英语看图说词闭环

- 完成录音、上传、候选词、发音证据、提示跟读、退出续测和结果保存。
- 结果页显示逐词状态、发音练习项和来源引用。
- 复用现有孩子选择、登录、历史结果、重新测试和安全分享流程。

### 阶段 3：延迟复测与第二任务

- 为提示后完成和发音不稳定的题项安排无提示复测。
- 增加 `英语听词选图`，验证同一个单词在接收与产出任务中的独立状态。
- 只在两个工具都稳定后抽取共享任务协议和掌握图组件。

### 阶段 4：中文结构化任务

- 在不改变现有识字量结果的前提下，评估 `中文字词朗读` 或 `中文听写`。
- 复用引用层、任务协议、证据评分和复测机制。
- 中文与英文只共享工程对象，不共享未经证明的评分阈值。

## 验收标准

- 每个测试定义都能说明输入、响应、测量对象和活动模式。
- 每条面向用户的标准或技术能力声明都能追到具体引用及其限制。
- 历史结果锁定题库、协议、评分规则和引用版本。
- 英语看图说词能区分独立说出、发音需练习、提示后会读、暂不会和录音无效。
- 提示或跟读不会覆盖首次独立作答证据。
- 供应商低置信度、静音和噪声不会被计为孩子不会。
- 家长复核有痕迹，且不修改原始自动证据。
- 结果只报告固定题库内的精确数量，不外推完整词汇量或官方等级。
- 延迟复测能说明为什么再次出现该词，并保留前后证据。
- AI 解释或练习不拥有正式题库和掌握状态的写权限。
- 录音、孩子档案、账号、分享和缓存遵守现有边界。

## 剩余假设与风险

- 本设计把用户口述的 `CEM` 理解为 `CEFR`，把“进销存”理解为接收、产出、互动和中介四种语言活动。
