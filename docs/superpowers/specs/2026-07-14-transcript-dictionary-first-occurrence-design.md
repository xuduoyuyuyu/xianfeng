# 小程序逐字稿教育词典首次高亮设计

## 目标

在小程序原生节目详情页的逐字稿正文中，同一个教育词典词条只在整期节目首次出现时高亮并可点击查看释义，后续重复出现保持为普通正文。

## 范围

- 仅调整节目详情页逐字稿正文的词典匹配展示。
- 不改变后台接口、`dictionaryEntries` 数据、逐字稿原文或时间戳。
- 不调整现有词条弹窗的内容和关闭方式。

## 核心规则

- 去重范围是整期节目的完整逐字稿，不是单个段落或单个嘉宾发言。
- 正式词条名和其别名共用同一个词条身份。任一名称首次命中后，该词条的正式名和其他别名在后文中均不再高亮。
- 仍按逐字稿从前到后、每段从左到右确定“首次”。
- 多个候选词在同一位置重叠时，继续使用现有的最长词优先规则。
- 后续重复词仅取消高亮和点击行为，不删除、折叠或改写原文。

## 数据流

1. 节目详情数据按现有逻辑规范化有效词条、正式名和别名。
2. 解析完整逐字稿时建立一个当期节目专用的“已高亮词条”集合。
3. 每次命中词条时，若词条未记录，生成可点击的词典节点并记录该词条。
4. 若词条已记录，将当前命中文字生成普通文本节点。
5. 段落间共用该集合，直到本期逐字稿解析完成。

## 异常与回退

- 没有有效词典数据时，逐字稿继续按普通文本展示。
- 没有命中词条时，正文不变。
- 已高亮词条的后续命中不再具有词典点击数据，避免视觉取消高亮但仍能触发弹窗。

## 验证

- 同一段落中同一词条出现多次，只有第一次是词典节点。
- 同一词条跨段落出现，只有整期首次是词典节点。
- 正式名与别名交叉出现时，共享一次高亮机会。
- 重叠词条仍按最长词优先匹配。
- 逐字稿文字拼接后与原文完全一致。
- 运行小程序相关静态测试和完整发版前验证脚本。

## 非目标

- 不修复或重新生成后台逐字稿。
- 不在其他页面扩展教育词典高亮。
- 不新增词条搜索、收藏、统计或用户可配置的高亮次数。
