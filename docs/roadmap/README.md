# Roadmap

Roadmap items are repository-level workstreams. This is an index, not a second
issue tracker. If an external task system becomes the source of truth, record
the external ID here and keep details there.

## Buckets

- [Active Roadmap](active-roadmap.md)
- [Deferred Roadmap](deferred/README.md)
- [Obsolete Roadmap](obsolete/README.md)

## Status Vocabulary

- `proposed`: Candidate work; not started.
- `active`: Current work.
- `blocked`: Cannot proceed without an external decision or dependency.
- `completed`: Done and verified.
- `deferred`: Accepted for later, not current scope.
- `obsolete`: No longer applicable; retained for history.
